# 🚀 Space Sporcle

A command-line space-themed quiz game written in C and developed for TigerHacks.

## About

Space Sporcle is an interactive quiz game that lets players test their knowledge of space through four different games:

1. **Guess the Planet** – Identify a planet from clues.
2. **Name the Planets in Order** – Enter the planets in their correct order from the Sun.
3. **Weight Calculator/Quiz** – Calculate your weight on different planets and answer weight-related questions.
4. **Star, Moon, or Galaxy?** – Identify whether a given object is a star, moon, or galaxy.

Players can choose which game they want to play from the main menu and receive immediate feedback and scoring throughout each game.

## Features

- Four interactive space-themed quiz games
- Randomized questions and prompts
- User input and answer validation
- Score tracking
- Immediate feedback for player responses
- Multiple attempts for certain questions
- Command-line interface with colored output
